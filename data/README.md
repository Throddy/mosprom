# Данные

Какие данные лежат в репозитории и для чего: видео для подбора порогов, демо-стенда и быстрого запуска, разметка контрольного набора.

## Состав

Все данные лежат в git, видео до 95 МБ на файл.

| Папка или файл | Назначение | Файлов | Размер, МБ |
|---|---|---|---|
| `data/videos/dev/` | набор для настройки порогов правил, разметка `labels.csv` | 7 | 253.8 |
| `data/videos/demo/` | копии 720p для демо-стенда и быстрого запуска, описание в `data/videos/demo/README.md` | 8 | 49.5 |
| `data/videos/holdout/` | отложенное видео без нарушений | 1 | 12.9 |
| `data/test_set/` | разметка контрольного набора | 2 | 0.0 |
| `data/demo.mp4` | 10 с, для `scripts/smoke.py` | 1 | 0.4 |

Контрольного набора `data/videos/test/` в репозитории нет. Файлов больше 95 МБ нет.
