# Тестовый набор

Наборы видео для подбора порогов и для метрик и разметка контрольного набора. Набор dev лежит в git (`data/README.md`), видео контрольного набора в репозитории нет: они в общей папке, ссылка в `README.md`.

| Набор | Папка | Назначение | Разметка |
|---|---|---|---|
| dev | `data/videos/dev/` | подбор порогов правил (Максим) | `data/videos/dev/labels.csv` |
| test | `data/videos/test/` | независимый контрольный набор для метрик ML-7 | `data/test_set/labels.csv` |

Видео контрольного набора не используются для подбора порогов. Исходные `fall.mov`, `running.mov` и `danger_zone.mov` использовались для подбора порогов в BE-11 и относятся к dev. `running_02.mov` и `proximity.mp4` тоже относятся к dev и в контрольную разметку не входят.

## Разметка

`labels.csv`, формат раздела 8 `CONTRACT.md`: одна строка на одно нарушение, время в секундах от начала видео. Имена файлов совпадают с именами в `data/videos/test/` с учётом регистра.

| Видео | Нарушение | Интервал, с |
|---|---|---|
| `fall_02.mov` | `fall` | 7.0–24.0 |
| `running_03.mov` | `running` | 2.5–6.7 |
| `danger_zone_02.mov` | `danger_zone` | 8.0–18.0 |
| `running_04.mov` | `running` | 1.0–6.7 |

Метрики ML-7 по `running_04.mov` ещё не пересчитаны.

## Видео без нарушений

Строк в `labels.csv` у них нет. `ml/metrics.py` берёт все видео из папки `--videos`, видео без строк выбранных типов считает видео без нарушений и выводит число тревог на них и их общую длительность. Отдельный список не нужен: видео без нарушений контрольного набора определяются как видео в `data/videos/test/`, которых нет в `labels.csv`.

| Видео | Сцена |
|---|---|
| `normal_walking.MOV` | человек идёт по коридору, нарушений нет |

`ml/metrics.py` требует файл событий `<имя видео без расширения>.jsonl` для каждого видео в папке, поэтому в `data/videos/test/` должны лежать только видео контрольного набора.
