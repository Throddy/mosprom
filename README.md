# mosprom

Веб-сервис контроля нарушений техники безопасности по видео с камер. Нейросети выполняются на ускорителе LinQ TPU. Кейс LinQ, хакатон «Открой#Моспром», 23–25 октября 2026.

## Запуск

Полный порядок запуска будет описан в задаче FE-8.

### Фронтенд

Стек: Vite, React, TypeScript. Требуется Node.js `^20.19.0` или `>=22.12.0`.

| Действие | Команда в `frontend/` |
|---|---|
| Установка зависимостей | `npm ci` |
| Dev-сервер | `npm run dev` |
| Сборка | `npm run build` |
| Просмотр сборки | `npm run preview` |

- Dev-сервер: `http://localhost:5173`. Запросы `/api`, `/ws` и `/media` проксируются на бэкенд `http://localhost:8000`.
- Сборка попадает в `frontend/dist/`. Бэкенд раздаёт её по `/`: `http://localhost:8000`.
- Просмотр сборки: `http://localhost:4173`, проксирование то же, что у dev-сервера.
